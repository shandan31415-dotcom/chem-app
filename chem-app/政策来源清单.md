## 一、收录原则（三条硬规矩）

1. **只收官方站**：域名必须是 `*.gov.cn`（国务院部门官网、山东省政府部门官网）。行业媒体、公众号、协会转载一律不收。
2. **只收公文原文**：通知、办法、规定、方案、规划、公告、目录、标准、清单。**不收**「一图读懂」「答记者问」「政策解读」「专家推荐」「职称评审」「表彰培训」——这些是二次加工或事务性文件，不能当依据。
3. **逐条回源校验**：入库前打开原文，页面标题含「页面不存在 / 404 / 系统维护」直接丢弃；入库后增量累积，不因列表翻页而删除。

## 三、什么样的政策算「涉及会员行业」——四层判定

按顺序判断，命中即收：

1. **强相关（标题有行业词）**：化工、石化、化学、炼化、炼油、氯碱、化肥、农药、轮胎、橡胶、涂料、塑料、新材料、危险化学品、危化、精细化工、煤化工、焦化、盐化工、纯碱、烧碱、甲醇、烯烃、芳烃、树脂、氟化工、硅材料、锂电材料、助剂、化工园区 → 必收
2. **强主题（跨行业，但化工迟早被覆盖）**：碳市场、碳排放权、碳交易、碳配额、碳足迹、碳标签、碳关税、CBAM、零碳工厂、零碳园区、近零碳、能耗双控、节能降碳、绿电、绿证、碳排放 → 必收，**哪怕标题写的是钢铁水泥**（碳市场扩围下一个就是化工，提前看到才有准备）
3. **弱主题（名单类/单项）**：绿色工厂、绿色制造、绿色供应链、清洁生产、循环经济、资源综合利用、工业固废、再生资源 → 收；但纯非化行业专项（纺织、食品、家电、家具、船舶、航空、医药）剔除
4. **源内中相关（仅在行业属性明确的信源上）**：省生态环境厅稿件里的园区、排污、环评、危废、固废、许可、产能、两高 → 收

**明确排除**：钢铁、水泥、玻璃、陶瓷、有色、冶炼、造纸、印染、核电、核技术、火电、机动车、农村、宅基地、土壤、地下水、生态保护、湿地、碳汇、生态补偿 —— 前提是标题里没有化工类强词。

## 六、人工补录通道（上面这几家的补法）

自动抓不到的栏目，走人工。每月十分钟，能把绿色工厂名单、危化品新规这两块补上。

**操作三步：**

1. 打开 `chem-app/data/manual_policies.csv`（Excel / WPS 直接双击就能编辑）
2. 一行一条，照表头填：

   | 列 | 说明 |
   |---|---|
   | 标题 | 与政府站标题一字不差，至少 8 个字 |
   | 发文机关 | 写全称，如「中华人民共和国工业和信息化部」 |
   | 层级 | **只能填**「国家级」或「山东省」（小程序政策页只有这两个分组） |
   | 发布日期 | `2026-11-01`，也认 `2026/11/1`、`2026年11月1日` |
   | 原文链接 | 必须 `http://` 或 `https://` 开头，域名必须是 `.gov.cn` |
   | 影响提示 | 选填，一两句话说明对会员的影响，会显示在政策详情页 |
   | 内部备注 | 选填，只给自己看，不展示 |

3. 存盘后跑：

   ```bash
   cd chem-app
   python scripts/merge_manual_policies.py --dry-run   # 先看结果，不写文件
   python scripts/merge_manual_policies.py             # 确认无误再真写
   cd ../mini && python scripts/build_data.py          # 重建小程序数据 + 云端快照
   ```

**脚本会把关的**：标题太短、层级填错、日期认不出、链接不是 `.gov.cn`、库里已有同一条（链接或标题重复），都会列出行号报错并跳过，不会写进库。所以填错了不用怕，跑一遍就知道。

**人工条目有豁免权**：标了 `source: manual` 的条目，不会被自动采集的书名号去重合并掉，也不会因为「标题里没有化工关键词」被过滤。所以哪怕标题是《关于公布2026年度绿色工厂名单的通知》，也留得住。

**表里的「示例-…」那行不用删**，脚本自动跳过。
