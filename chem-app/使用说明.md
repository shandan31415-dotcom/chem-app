# 高端化工 · 行业认知 App

给一个人用的行业认知工具。每天打开三分钟，攒行业底子。  
按 `PRD.md` v1.1 实现。

---

## 〇、地图模块：全省化工企业目录 + 搜索

打开底部「地图」，是山东 16 地市的真实边界图：

- **搜索栏（最上面）**：直接搜地市名、园区名、企业名或产品词（万华 / MDI / 轮胎 / 纯碱 / 地炼），结果按「地市 → 园区 → 企业」排序，点一下直达详情页
- **颜色深浅 = 该市收录的高端化工企业数量**（0 / 1 / 2–3 / 4+），一眼看出高端集中在哪
- 每个市下面标了「N园」，是收纳的化工园区数
- **点任意地市** → 产业概况、体量定位、产业集群、本地重点品种、撮合判断要点、园区列表、市级重点企业
- **点品种标签** → 自动跳到地图页搜出全省做这个品种的企业
- **点园区** → 园区定位与园内企业；**点企业** → 产品范围、所属品类、所属地市、企业动态

收录口径：**不限高端化工，化工领域企业都收**。园区归属明确的放在园区下，归属拿不准的放在「市级重点企业」，不硬凑归属。

淄博地块南北狭长，放不下横排地名，用了白底名牌标注。

## 〇之二、品类模块：73 个品类，12 组

从 12 个扩到 73 个，按「高端新材料 / 电子与半导体 / 烯烃与塑料 / 聚氨酯 / 聚酯与化纤 / 氯碱纯碱卤水 / 农化与化肥 / 橡胶与轮胎 / 新能源材料 / 基础原料与炼化 / 精细与配套 / 制冷剂」分组。

每个品类都是同一套六问：**成本锚、需求锚、供给格局、山东的位置、流向、储运门槛**，再加代表产品与头部企业。

品类页顶部有搜索框，输入 MDI、纯碱、轮胎都能直接筛出来。

## 一、怎么跑起来

### 本地预览（现在就能看）

```bash
cd chem-app
python server.py          # 默认 8893 端口
```

浏览器打开 `http://127.0.0.1:8893/`。  
模拟手机：F12 → 打开设备工具栏 → 选 iPhone/安卓机型。

### 只更新数据

```bash
python scripts/fetch_all.py
```

### 装到安卓手机

1. 把这个目录发布到任意静态托管，拿到网址
2. 手机 Chrome 打开 → 右上角 ⋮ → **安装应用**
3. 桌面出现图标，点开全屏、无地址栏，

> 用微信/QQ 打开再「添加到桌面」只会得到快捷方式，点开还是浏览器，别用那个。

## 三、数据从哪来

| 模块   | 来源                               | 更新方式     |
| ---- | -------------------------------- | -------- |
| 资讯   | 中国化工报、中国化工信息周刊、隆众资讯、中新网          | 每次打开自动刷新 |
| 行情   | 东方财富期货接口（23 个品种主连 + 日线）          | 自动       |
| 政策   | 山东省工信厅（法规/其他文件）、国家发改委、生态环境部      | 自动       |
| 品类   | 人工整理                             | 手动       |
| 园区企业 | 人工整理（地市 → 园区 → 企业三层）             | 手动       |
| 地图边界 | 阿里云 DataV 公开行政区划 GeoJSON，投影简化后内嵌 | 一次性生成    |

**「高端化工」怎么筛的**：先用品类关键词（MDI、PVDF、己内酰胺、POBA…）匹配，再补一条「化工 + 新材料/高端/特种/投产」的组合规则。宁可多收，不漏。

**板块怎么分**：标题里出现山东地名**或**园区名录里的山东企业名 → 山东；来自国际频道或含境外关键词 → 全球；其余 → 全国。

## 四、六七个必须知道的边界

1. **期货价 ≠ 现货价**。行情页是期货主连，看趋势可以，报价仍以生意社/隆众/卓创现货价为准。
2. **AI 推断会错**。品种详情里标了「AI 推断，仅供参考」，依据是把关联新闻标题按成本端/供给端/需求端/库存/政策分类，**不是人工核实**。拿不准就看下面列的原文。
3. **企业动态是自动匹配的**。资讯标题里出现企业名才算，没匹配到就明说「近期暂无收录」，不编造。
4. **企业名录不是工商全量**。16 地市共 32 个园区、157 家企业，是按规模和名气挑的「重点/代表性企业」，覆盖全省化工的主体，但离「所有化工企业」还有距离（山东化工企业上万家）。     
   标「待核」的条目（园区归属或产品线）建议以官方公示核对后再对外引用。     
   日照目前只有 1 个园区与 4 家企业，聊城高度集中在鲁西化工，都是拿不到更多可靠来源，宁可少不编。
5. **「高端为主 / 高端+基础 / 基础为主」说的是园区主导方向，不是高端企业占比。**     
   例如桓台马桥标「高端为主」，因为东岳定义了它的产业属性，但名录里还列了两家地炼做对比。
6. **全球板块会偏少**。目前以中文化工媒体为主，国际上发生的事不一定当天有中文报道。
7. **政策只收录标题+原文链接**，不做全文摘要，避免误读。
8. **离线缓存不是备份**。真正属于你的只有「已学、已读、收藏」，双击顶部标题进入「我的数据」可导出 json。

## 五、改哪里

| 想改        | 改哪个文件                                                    |
| --------- | -------------------------------------------------------- |
| 加/减化工品种   | `scripts/fetch_all.py` 里的 `PRODUCTS`                     |
| 调整高端化工关键词 | 同文件 `KW_CATEGORY` / `KW_HIGH` / `KW_CHEM`                |
| 加新闻源      | 同文件 `fetch_news()` 里的 `jobs`                             |
| 加政策源      | 同文件 `POLICY_SOURCES`                                     |
| 改品类内容     | `data/categories.json`（或改 `scripts/_data_cat.py` 后重跑 build_enrich）  |
| 改园区和企业    | `data/parks.json`（cities → parks → enterprises 三层）       |
| 批量补地市/企业  | 改 `scripts/_data_city.py` / `_data_ent.py` → `python scripts/build_enrich.py` |
| 重新生成地图    | `python scripts/build_map.py`（需先有 `scripts/tmp/sd.json`） |
| 改板块判定规则   | `scripts/fetch_all.py` 的 `enrich()`                      |

改完跑一次 `python scripts/fetch_all.py` 就生效。
