### 服务内容标识的选择依据（官方原文，被质疑时可引用）

《小程序备案服务内容标识选择指引》「工具」一级下原文：

- **报价/比价**：适用于提供**商品价格展示/价格对比**等服务
- **信息查询**：适用于提供**信息查询**、订单功能等服务

单位备案口径：**可选，需符合单位经营范围**（协会对应业务范围）。

### 绝对不要选（会触发资质要求）

| 不能选 | 原因 |
|---|---|
| 金融业 › 证券/期货 | 需金融主管部门审批资质，拿不到 |
| 金融业 › 股票信息服务平台 | 同上 |
| 政务服务 › 时政信息 | 仅限政府机关、事业单位 |
| 其他 › 宗教信息 | 需《互联网宗教信息服务许可证》 |
| 其他 › 咨询广场 | 虽可选，但释义为「行业资讯信息」，会把性质拉向内容资讯，不如工具准确 |

### 服务内容描述（完整版，直接复制）

```
本小程序由山东省高端化工产业发展促进会主办，面向会员单位及化工行业从业者提供
公开信息查询服务。主要内容包括：山东省16地市化工园区分布示意、园区内企业名录、
化工产品品类说明与产业链定位、化工原料公开市场报价展示，以及化工相关政策原文
查阅。所有内容均整理自政府公示、企业公开资料和公开市场报价，不提供交易、支付、
订单等信息发布服务。
```

## 六、绝对不能出现的词

提交前把这段描述再读一遍，确认没有以下词：

`交易` `撮合` `买卖` `询价` `期货` `主连` `收盘` `金融` `投资` `资讯` `新闻`

出现任意一个，会被按危化品经营或金融信息服务判断，要求提供对应许可证。
