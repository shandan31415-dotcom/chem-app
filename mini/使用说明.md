## 二、改东西的正确姿势

| 要改什么 | 改哪里 | 然后 |
|---|---|---|
| 园区 / 企业 / 地市数据 | **不改小程序**，改 `chem-app/data/parks.json`（或它的 `scripts/_data_*.py` 源） | 跑 `python scripts/build_data.py` |
| 品类 / 板块 / 产业链 | 同上，改 `chem-app/data/*.json` | 跑 `python scripts/build_data.py` |
| 地图配色 | `tools/render_map.js` 里的 `HEAT` 常量 | 跑 `node tools/render_map.js` |
| 页面样式 / 文案 | `pages/**` 与 `app.wxss` | 重新编译 |

⚠️ **`mini/data/*.js` 是生成物，手改会被下次构建覆盖。** 源数据只有一份，在 `chem-app/data/`。

## 三、五条命令

```bash
cd mini

# 1. 重新生成数据（改了 chem-app/data 之后必跑；同时更新云端快照）
python scripts/build_data.py

# 2. 重新渲染山东地图 PNG（改了配色或地市轮廓之后）
node tools/render_map.js

# 3. 静态自检：语法 / JSON / WXML 标签 / 页面注册 / 跳转目标
node tools/check.js

# 4. 逻辑冒烟：统计口径、检索、参考价、走势、本机记录
node tools/smoke.js

# 5. 云端通道冒烟：三级回退、坏数据拒绝、订阅通知（不联网）
node tools/smoke_live.js
```

构建工具依赖装在**仓库根**的 `node_modules/`（`cd .. && npm install`），**不要**装在 `mini/tools` 下。
`mini/` 整个目录会被算进小程序代码包，而主包上限是 2MB；依赖装进去会直接超限，编译不通过、模拟器白屏。

## 四、结构

```
mini/
├── app.json / app.js / app.wxss     入口、tabBar、全局设计系统
├── data/                            生成物：由 chem-app/data 转出的 JS 模块
├── assets/map/                      3 张预渲染地图 PNG（热力/产业集群/产业布局）
├── pages/                           13 个页面
│   ├── parks  cats  prices  policies  me     ← 5 个 tab
│   └── city park ent cat board chain price policy  ← 8 个详情页
├── utils/core.js                    纯逻辑，从 web 版原样移植（无 wx / 无 DOM）
├── utils/live.js                    云端数据通道：云库 → 缓存 → 包内 三级回退
├── utils/config.js                  合规配置 + 云开发环境 ID
├── utils/store.js                   本机记录：已学/已读/收藏
├── cloudfunctions/syncData/         云函数：每天把快照灌进云数据库（不进包）
├── scripts/build_data.py            JSON → JS，并产出云端快照
└── tools/                           构建脚本与自检（不进包）
```

## 五、和网页版的三处有意差异

1. **没有资讯模块**——小程序内容聚合审核风险高，且外链打不开。只保留政策原文。
2. **行情叫「参考价」，只画收盘折线**——不出现 K 线蜡烛图、不出现交易术语，降金融类目风险。
3. **政策原文不能直接打开**——微信拦外部政府网站，改为「复制链接 → 手机浏览器打开」。

## 七、数据从哪来（两套，别搞混）

| | 内容 | 更新方式 |
|---|---|---|
| **代码包内** `data/*.js` | 园区 / 企业 / 品类 / 产业链 + 政策、行情的兜底副本 | 改 `chem-app/data` 后跑 `python scripts/build_data.py`，随版本发布 |

`utils/live.js` 负责把云库那份盖到 `core.D` 上，读不到就用包里的。所以**页面代码不用关心数据从哪来**。

政策页、参考价页支持**下拉刷新**（手动催一次云端，绕过 10 分钟冷却）。
