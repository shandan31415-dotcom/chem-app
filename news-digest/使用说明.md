# 化工每日资讯 · 手机 App

一个装在手机桌面上的应用：点开就能看**化工品种实时价格**和**每日分类资讯**。
只读浏览，不用登录，不用编辑，数据自动更新。

---

## 一、它是怎么工作的（30 秒看懂）

```
         抓取（fetch.py）
              │  化工期货行情 + 5 类新闻
              ▼
          data.json
              │
     ┌────────┴────────┐
     │                 │
  服务端模式         静态模式
  打开即刷新        定时任务每天跑一次
     │                 │
     └────────┬────────┘
              ▼
        手机 App 打开 → 显示
```

三个关键点，决定了它**永远不花钱**：

1. **定时/刷新都不在你的手机上**。手机熄屏会杀掉后台任务，这个坑绕开了。
2. **不需要数据库**。数据就是一个 JSON 文件。
3. **只读**。没人写数据，就没有并发、账号、权限这些麻烦事。

## 二、文件清单

| 文件 | 作用 | 要不要改 |
|---|---|---|
| `index.html` | 应用界面（全部逻辑在这一个文件里） | 一般不动 |
| `data.json` | 抓取出来的数据 | **不要手改**，自动覆盖 |
| `fetch.py` | 抓取脚本，纯标准库，不用装依赖 | 想加新闻源时改 |
| `server.py` | 带自动刷新的服务端 | 不动 |
| `sources.json` | 新闻源、化工品种清单 | **主要改这里** |
| `manifest.webmanifest` | 告诉手机「我是一个 App」 | 不动 |
| `sw.js` | 离线缓存，断网也能看上次内容 | 不动 |
| `icons/` | 桌面图标 | 不动 |
| `.github/workflows/daily.yml` | 定时任务配置（方式二用） | 改时间时改这里 |

## 三、两种上线方式，选一种就够

| | 方式一：云端托管 | 方式二：GitHub 静态托管 |
|---|---|---|
| 数据怎么更新 | **每次打开自动拉最新**（服务端后台刷新） | 每天定时跑一次 |
| 要配置吗 | 不用，给你链接就能用 | 要建仓库、开 Pages，约 10 分钟 |
| 花钱吗 | 不花 | 不花 |
| 适合 | 想马上用、不想折腾 | 想自己完全掌控 |

两种方式用**同一套文件**：`index.html` 会先试 `/api/data`（方式一提供），失败就退回读 `data.json`（方式二提供）。换方式不用改代码。

## 四、方式一：云端托管（零配置）

1. 我发布后会把一个链接给你；
2. 手机浏览器打开这个链接；
3. 按下面第五节的方法添加到桌面，结束。

数据会在**每次打开时自动检查刷新**：超过 10 分钟就后台悄悄更新一次，你打开时永远秒开（先显示缓存，再换成最新的）。

## 五、装到手机桌面（两种方式都一样）

**iPhone：**
1. 用 **Safari** 打开链接（必须 Safari，微信内置浏览器不行）
2. 点底部中间的 **分享** 按钮 ⬆️
3. 往下滑，选 **「添加到主屏幕」** → 添加

**安卓：**
1. 用 **Chrome** 或系统浏览器打开
2. 点右上角 **⋮**
3. 选 **「安装应用」**（有的机型叫「添加到主屏幕」）

完成后桌面上会出现一个**苯环图标**，点开是全屏的，**没有地址栏、没有浏览器按钮**，和普通 App 一样。

## 六、方式二：GitHub 静态托管（约 10 分钟）

### 第 1 步：建仓库

1. 打开 <https://github.com> 注册或登录（免费）
2. 右上角 **+** → **New repository**
3. 名字随便起，例如 `chem-news`
4. 选 **Public**（公开仓库的定时任务时长不限，完全免费）
5. 勾上 **Add a README file** → Create

### 第 2 步：上传文件

仓库页面点 **Add file** → **Upload files**，把本文件夹里的**所有文件和文件夹**拖进去。

⚠️ 两个必须注意的地方：

- `.github` 文件夹是隐藏的，Windows 资源管理器默认看不到。上传后检查仓库首页顶部有没有出现 **Actions** 标签页——没有就说明 `daily.yml` 没传上去，需要手动新建路径 `.github/workflows/daily.yml` 再传一次。
- 保持目录结构不变，`index.html` 必须在**根目录**，不能套一层文件夹。

提交信息随便写，点 **Commit changes**。

### 第 3 步：开启网页访问

1. 仓库 → **Settings** → 左侧 **Pages**
2. **Source** 选 `Deploy from a branch`
3. **Branch** 选 `main`，文件夹选 `/ (root)` → **Save**
4. 等 1～2 分钟，刷新页面，顶部会出现网址，形如：
   `https://你的用户名.github.io/chem-news/`

**这个网址就是你的 App 地址。**

### 第 4 步：先运行一次

仓库 → **Actions** 标签 → 左侧「每日更新资讯」→ 右侧 **Run workflow** → 绿色按钮。

等 1 分钟变绿勾，回到第 3 步的网址，就能看到价格和资讯。
（不点的话，要等第二天早上 7 点才会自动跑第一次。）

### 第 5 步：装到手机桌面

回到第五节。

## 七、日常维护

### 改更新时间

打开 `.github/workflows/daily.yml`，改这一行：

```yaml
- cron: "0 23 * * *"
```

**这里用的是 UTC 时间，比北京时间晚 8 小时。** 想早上 7 点更新，就写前一天 23 点。

| 想要的时间（北京） | 写什么 |
|---|---|
| 07:00 | `0 23 * * *` |
| 08:30 | `30 0 * * *` |
| 12:00 | `0 4 * * *` |
| 18:00 | `0 10 * * *` |

### 加 / 减新闻源

打开 `sources.json`：

- 某个分类不想看了 → 把它的 `"enabled": true` 改成 `false`
- 想加化工品种 → 在 `groups` 里对应分组下加名字，例如 `"瓶片"`、`"烧碱"`
- 想整块关掉 → `prices` 下面的 `"enabled"` 改成 `false`

改完提交，下次自动生效。

### 想立刻刷新一次

方式一：手机上打开 App 点右上角 **⟳**。
方式二：Actions → 每日更新资讯 → Run workflow。

## 八、数据从哪来

| 分类 | 来源 | 说明 |
|---|---|---|
| 化工价格 | 东方财富行情接口 | 23 个化工品种**期货主连**价格与涨跌幅，红涨绿跌 |
| 宏观快讯 | 华尔街见闻 | 实时财经快讯，含大宗商品报价 |
| 国内 / 国际 / 财经 / 社会 | 中国新闻网 RSS | 官方媒体，稳定、无需授权 |

**这些全是公开可访问的接口，不用注册、不用付费。** 但边界要说清楚：

- 自己看、公司内部几个人看 → 没问题
- 对外做成产品发布 → 需自行确认各来源的转载授权

**期货价格是期货价，不等于现货成交价。** 看趋势没问题；真要对外报价，仍以生意社、隆众、卓创的现货价为准。这几个平台的深度数据是付费订阅，没有免费接口——这跟花不花钱无关，是数据本身不开放。

## 九、几个会踩的坑

1. **定时任务不保证准点**，高峰期可能延迟十几分钟到半小时。做「每天早上看一次」足够，做盘中盯盘不行。
2. **刚装完图标还是旧内容**：浏览器缓存了。在 App 里点 ⟳，或删掉图标重新添加。
3. **iPhone 必须用 Safari 添加**。在微信/QQ 里打开再添加到桌面，出来的会有地址栏。
4. **公开仓库意味着数据公开**。这里只有公开新闻和行情，无所谓；但**不要往这个仓库放客户台账**。
5. **新闻源可能某天失效**。脚本有保护：单个源挂掉，其他照常更新，挂掉那个显示上次内容并给出提示，不会整页空白。
